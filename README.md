# Black Friday VPS Deals Landing Page

A responsive, single-page Black Friday VPS hosting deals comparison page prepared for GoogieHost.

## Files
- `index.html` — complete landing page with embedded responsive CSS and deal comparison content.

## Preview locally
Open `index.html` in any modern browser.

## Publish with GitHub Pages
1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose the `main` branch and `/(root)`, then save.
4. GitHub Pages will provide the published URL after deployment.

## Important pricing note
Prices and discounts in the page are indicative reference details, not live-verified checkout quotes. Promotions, coupon eligibility, renewal rates, taxes and plan specifications can change. Verify every offer with the provider before publishing or purchasing.
